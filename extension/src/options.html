Sites that open in Universal PDF

PDFs on these sites open in Universal PDF instead of the browser's viewer. Everywhere else is untouched — click the toolbar button when you want a one-off.

    On these sites the document is downloaded a second time so that Universal PDF can open it. That is invisible for ordinary files, and it carries your login for the site — but a link that only works once, such as a one-time download or a file behind a form you have just submitted, cannot be fetched twice and will not open. Use the toolbar button for those: it reads the document the browser already has.
